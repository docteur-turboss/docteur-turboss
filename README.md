<td width="55%">

I'm Horus, a self-taught developer from France 🇫🇷. I started out full-stack; these days most of what I write is backend TypeScript.

Right now that's [trading-model](https://github.com/docteur-turboss/trading-model): a trading platform split into 8 services, where agents learn to trade through a genetic algorithm and Deep Q-Learning. The goal is the same as on day one, a trading model and a risk analyzer for my own financial management.

I also write Discord bots. One runs my community server, the other ([BaByzAim](https://github.com/docteur-turboss/BaByzAim)) does moderation, tickets and anti-raid.

Before that I founded [Cash Sights](https://github.com/Horus-Turboss-Finance), a personal-finance app built as microservices. It's stopped now.

I test a lot, probably too much: unit and e2e tests, mutation testing with Stryker, scripts that flag dead code and duplication.

Ask me anything [here](https://github.com/docteur-turboss/docteur-turboss/issues).

</h2>

<table>
<tr>
<td width="50%" valign="top">

### 📊 [trading-model](https://github.com/docteur-turboss/trading-model)

Pulls market data from Binance, then trains trading agents with a genetic algorithm and Deep Q-Learning.

- 8 services: discovery server with TTL leases + HMAC tokens, topic pub/sub broker, DLQ with replay, API gateway, immutable audit log
- mTLS between every service, issued by SPIRE (TLS 1.3)
- MongoDB · MySQL · Redis Sentinel
- Prometheus · Grafana · Jaeger · Loki
- Jest + Stryker mutation testing, decisions written down as ADRs

</td>
<td width="50%" valign="top">

### 🛡️ [BaByzAim](https://github.com/docteur-turboss/BaByzAim)

A Discord bot that does a bit of everything.

- Moderation, tickets, giveaways, games, temp voice channels, reaction roles
- Anti-raid, anti-spam and anti-nuke protections
- Bun · discord.js · PostgreSQL + Drizzle · Redis + BullMQ
- Pino logs, Prometheus metrics, automated backups
- Vitest unit / integration / e2e, Docker deploy

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🧬 [goth-mommy](https://github.com/fox3000foxy/goth-mommy) (contributor)

fox3000foxy's genetic algorithm library in TypeScript, with zero dependencies. It searches hyperparameters (real, integer, boolean, categorical) and solves ordering problems like TSP or scheduling.

</td>
<td width="50%" valign="top">

### 🤖 [discord-horus-bot](https://github.com/docteur-turboss/discord-horus-bot)

The bot of my community server. TypeScript, discord.js v14, config checked with Zod, Jest tests.

</td>
</tr>

My old personal-finance platform: an API gateway, user and finance microservices, an address manager, a web interface and a Discord bot.
